# 第四阶段：扫描任务

## 架构评审

- 评审结论：通过。任务编排与漏洞明细解耦，本阶段交付任务生命周期、资产快照、知识版本快照、结果汇总和报告接口。
- 状态机：`queued -> scanning -> aggregating -> completed`；执行异常进入 `failed`，排队、扫描或汇总阶段允许进入 `cancelled`。终态不可再次启动或取消。
- 历史约束：重跑创建新任务并写入 `rerun_of_id`，原任务、执行日志、结果和报告保持不变。
- 安全边界：扫描模式固定为只读；通过服务端解密 SSH 凭据读取系统版本、软件包清单和监听端口，不执行提权、安装、修复或远端写文件。任务资产快照不包含 SSH 密文，浏览器与报告均不能读取凭据明文。
- 判定边界：厂商公告优先于通用版本比较，无法确定发行版 backport 时计入“需人工确认”。任务固定引用创建时的活动知识库版本。
- 页面边界：本页用于创建、筛选、启动、取消、重跑和下载报告；逐条漏洞及完整证据链在下一阶段“漏洞详情”展示。

## 页面设计

页面包含任务总数、运行中、已完成和失败/取消指标；工具栏按名称、类型和状态筛选；任务表展示资产数、只读标识、知识版本、进度、创建时间及上下文操作。新建抽屉使用扫描类型分段控件和资产多选，任务详情抽屉展示状态轨迹和风险汇总。

## API

### 2026-10-12 管理员删除与页面精简

- 任务统计改为标题旁紧凑摘要；未选择任务时隐藏批量工具栏，选中后显示原有五类操作及管理员删除。原有筛选、分页、详情和报告保留。
- `DELETE /api/v1/scan-tasks/{id}`：仅真实管理员登录会话可删除 completed/failed/cancelled 任务，传入 `{confirmation: "DELETE {id}", reason: "删除原因"}`；文本及原因均去除前后空格，原因长度 3..1000，成功返回 204。
- 页面单项/批量删除均人工确认；批量确认内容为 `DELETE N`（实际符合条件的任务数），明确显示跳过数；单次最多 100 项，串行请求，401/403/5xx/网络结果不明时中止，不自动重试。
- 删除为不可恢复的业务移除：独立 `scan_task_removals` 保存真实操作人 ID、名称、时间、原因及白名单任务快照，与统一审计共用同一记录。扫描任务、漏洞和报告不物理删除，既有历史详情仍可追溯。
- 当前/归档/全部扫描列表、计划任务列表及总览的当前扫描统计排除已删除任务；历史漏洞及报告不排除。已删除任务不能启动、取消、重跑、归档或恢复，关联资产不能通过测试清理绕过证据保留。
- 删除和其他写操作统一锁定并刷新任务；后台采集返回和汇总前复核状态，防止取消并删除后修改证据。SQLite 使用写锁，PostgreSQL 使用行锁。
- 独立迁移 `20261012_31` 直接继承生产 `20261007_30`；开发树 `20261012_33` 仅合并已存在的队列/恢复分支。发布此阶段不得自动升级工作区 head 或夹带未验收功能。

- 表头复选框全选当前页；“全选筛选结果”显式跨页选择，单次最多 100 项，超过上限不静默截断。修改筛选条件清空选择。
- 批量启动仅排队任务；取消仅非终态；重跑仅终态并新建排队任务、不自动启动；归档仅未归档终态，恢复仅已归档终态。确认弹窗展示实际任务和跳过数量。
- 批量操作逐条调用原接口，不是全有或全无事务；保留每项结果和失败项，权限失效或网络结果不明时停止后续请求，不自动重试。完成后重新读取服务端列表。

- 归档只移出当前列表，可在已归档视图恢复；报告、漏洞发现和原始扫描证据不删除。不存在普通业务物理删除入口。

### 既有接口

- `GET /api/v1/scan-tasks`：任务列表。
- `GET /api/v1/scan-tasks/{id}`：任务详情。
- `POST /api/v1/scan-tasks`：创建排队任务。
- `POST /api/v1/scan-tasks/{id}/start`：执行只读扫描并推进状态机。
- `POST /api/v1/scan-tasks/{id}/cancel`：取消非终态任务。
- `POST /api/v1/scan-tasks/{id}/rerun`：从终态任务创建新任务。
- `GET /api/v1/scan-tasks/{id}/report`：下载任务报告。
- `PATCH /api/v1/scan-tasks/{id}/archive`：归档/恢复终态任务，`archived` 为布尔值。列表通过 `archive_view=active|archived|all` 选择视图。

## 验收范围

- 创建任务时校验资产并保存资产与知识版本快照。
- 状态迁移可审计，非法迁移返回冲突。
- 取消和重跑不会覆盖原任务。
- 完成任务生成风险汇总与只读报告。
- 没有资产完成真实采集时任务进入失败，不能用全零结果伪装成功。
- 桌面和移动端可完成主要操作，无页面级横向溢出。
